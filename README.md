# Hu et al. (2020): DDM reproduction and reanalysis

## 01_reproduction_2020

[Reproduction instructions and file directory](01_reproduction_2020/README.md).

This workline contains Pilot and Confirm behavioral analyses, Confirm HDDM analyses, figure redraw code, and separately labeled sensitivity results. See its README for validation status, methodological differences and incomplete supplementary analyses. It is not a claim of complete reproduction of every published analysis.

The package includes the necessary inputs, code and selected results. Full historical model databases and local software libraries are not included. Default Figure 4 redraw uses the included compact samples; refitting requires the documented software dependencies. Configured historical database paths refer to the original local workspace and must be changed on another computer if using external full models.
